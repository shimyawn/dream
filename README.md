# Dream Factory

셰익스피어의 *한여름 밤의 꿈*에서 영감받은 인터랙티브 꿈 공장 시뮬레이션입니다.

낮에는 컨베이어 벨트 위에서 꿈이 제작되고, 밤이 되면 퍽(Puck)이 침입해 달콤한 꿈을 악몽으로 바꿉니다.
클릭으로 꿈을 지키거나 퍽을 저지하며 점수를 올리는 게임 요소가 포함되어 있습니다.

## Features

- 낮/밤 자동 전환 (배경, 색상, BGM 변화)
- 컨베이어 벨트 꿈 제작 시뮬레이션
- 밤 모드: 퍽 침입 이벤트 (클릭으로 방어)
- Sweet / Nightmare / Neutral 점수 시스템
- 레벨 시스템
- 셰익스피어 대사 인용

## Tech

- Vanilla JavaScript + HTML5 Canvas
- 단일 파일 (`index.html`)
- Press Start 2P 레트로 폰트
- 외부 라이브러리 없음
